# SoftRYT Frontend — Programmatic SEO & Affiliate Platform

SoftRYT Frontend is a fast, responsive, and SEO-optimized web application built using Next.js 16 (App Router), React 19, and Tailwind CSS v4. It dynamically fetches and renders AI-generated tool comparisons, detailed reviews, categories, and blog posts from a Supabase database. 

The frontend implements Incremental Static Regeneration (ISR) and is styled using a premium developer-grade design inspired by modern web aesthetics (clean dark modes, Sky-gradient hero elements, and clean grid components).

---

## 🚀 Key Features

### 1. Incremental Static Regeneration (ISR)
* **Pre-rendered Static Pages**: Reads all published slugs from Supabase at build time using `generateStaticParams` to ensure lightning-fast Page Speed and Core Web Vitals.
* **On-Demand Webhook Revalidation**: Exposes a secure `/api/revalidate` endpoint triggered by the FastAPI backend to instantly purge cache when new comparison or blog pages are generated or updated.
* **Auto-Revalidation**: Background ISR cache updates every 24 hours as a fallback security layer.

### 2. Custom MDX Rendering System
* **Statically Hydrated MDX**: Uses `next-mdx-remote` to parse Markdown generated by the backend AI writer, injecting bespoke React UI components directly into the text.
* **Specialized Content Components**: Supports custom comparison tables, highlight badges, callout cards, accordions, and comparison cards without compromising markup structure.

### 3. SEO & Structured Data (JSON-LD)
* **Metadata API**: Generates dynamic SEO titles, descriptions, open-graph elements, and canonical URLs for every comparison, review, and blog post.
* **Rich Snippets (JSON-LD)**: Injects structured JSON-LD schemas (such as Product Review, Article, or WebPage schemas) dynamically into the document `<head>` to gain rich search engine highlights.
* **Automated Robots & Sitemaps**: Utilizes dynamic `sitemap.ts` and `robots.ts` to automate search engine indexing discovery.

### 4. Click-Through & Affiliate Cloaking
* **Link Redirection**: Cloaks affiliate links using the `/api/go/[slug]` API endpoint.
* **CTR Tracking**: Automatically intercepts redirects, increments click tracking variables in Supabase, and runs a `307 Temporary Redirect` to the affiliate program or target SaaS website.

## 💻 Local Setup & Installation

### Prerequisites
* Node.js 18+ (Node 20+ recommended)
* npm, pnpm, yarn, or bun installed
* Running instance of SoftRYT Backend (optional, but needed to run/trigger generation pipelines)

### 1. Install Dependencies
Navigate to the frontend folder and run:
```bash
npm install
# or
pnpm install
# or
yarn install
```

### 2. Configure Environment Variables
Create a `.env` file (or copy `.env.example` if available) and add the following keys:
```ini
# Supabase Public Keys
NEXT_PUBLIC_SUPABASE_URL="https://your-project.supabase.co"
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY="sb_publishable_your_key_here"

# Supabase Service Key (used for page click tracking updates)
SUPABASE_SECRET_KEY="sb_secret_your_key_here"

# Security & Sync
REVALIDATION_SECRET="shared-secret-with-backend-for-cache-busting"
NEXT_PUBLIC_SITE_URL="http://localhost:3000"

# Developer Logo API integration token (Optional)
LOGO_DEV_TOKEN="your_logo_api_token"
```

### 3. Run Development Server
Start the Next.js local server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for Production
To generate optimized static builds and verify production readiness:
```bash
# Build the production application
npm run build

# Start the node server locally in production mode
npm run start
```
> [!TIP]
> Run `npm run lint` before committing code to ensure TypeScript and ESLint standards are clean.
